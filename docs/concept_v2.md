# Vive Gamer コンセプト v2 — 「バズるポートフォリオ」としての再定義

> v1（CLAUDE.md）との差分: 「マルチプレイパーティゲーム」から「1人でも完結するAI騙しおもちゃ + マルチプレイ拡張」へ構造を転換する。
> 判断基準は常に「その機能は、シェアされたカード/動画を面白くするか？」

## 1. 目的の再定義

ポートフォリオとして世の中にバズらせることがゴール。これは次の4要件を意味する。

1. **10秒で理解できる** — 見た人が最初の画面で「何をすればいいか/何が面白いか」を説明なしで掴める
2. **1人でも完結する** — バズで来た人は仲間を連れていない。その場ですぐ遊べなければ離脱する
3. **遊ばなくても伝わる** — シェアされたカードやGIFだけでも面白さが完結している
4. **技術力が伝わる** — コード・設計ドキュメントからエンジニアリング力が読み取れる

## 2. 原則: シェアカードから逆算する

Xでバズるのはゲームへのリンクではなく**スクショ・GIF**である（Quick, Draw! や Wordle の教訓: 拡散の単位は成果物）。

**目指す1枚**:
「私の絵に対して AI が『キリン』と答えた（正解: 肉まん）」
＝ 絵 + AIの誤答タイムライン + 「AI解読失敗」バッジ + スコア + ゲーム名/URL

重要な性質: **絵が下手でも成立する**。「AIにはこう見えたらしい」というオチは絵の質に依存しない。描くのが下手な人ほど面白いカードになる可能性がある＝誰にでもバズの口がある。

## 3. 構造転換: おもちゃファースト

```
現状:  ニックネーム入力 → ロビー → 2人以上必要 → モード選択
改訂:  トップページ = その場で描き始められるキャンバス（ソロおもちゃ）
        → AIがライブで推測（独り言が見える）
        → 終了したら共有カード自動生成 → Xでワンタップ共有
        → 「友達と対戦」ボタンでロビー/マルチプレイへ（既存機能）
```

- ソロモードでは人間の推測者はいない。「AIが当てたら負け」の CAPTCHA 突破型の一人遊びになる。これはこれで成立する（「AIに騙せた」という達成感）
- マルチプレイ（人間VS AI＋人間推測）は「友達がいる時の拡張」に格下げ。ただし実装は温存＝ポートフォリオの厚み・技術展示になる
- これで「2人集めないと見られない」という冷起動問題が消える

## 4. AIキャラ化（見せ物にする）

モード①のAI推測は現在「裏で8秒ごとに静かに走る」。これをショーにする。

- **アバター + リアルタイム独り言**: 「…猫？ いや、餃子？」と画面に吹き出しで流れる。この誤答ログこそが共有コンテンツの原料
- **温度上昇を演技に**: 既存の temperature 勾配（0.8→+0.1/回）を「AIの焦り」として演出（吹き出しに「ミスった…」等の情感を足す）
- **正解時**: 挑発演出（「43秒かかりましたね humans」）
- 誤答が面白いほどカードが面白い＝**ゲーム設計と拡散設計が同じものを指す**状態が理想

## 5. 共有カード仕様（viral wedge の本体）

- 内容: お題（モザイク可） / 完成絵 / AIの回答履歴（誤答を強調、時系列で） / 「AI解読失敗」バッジ+スコア / ゲームロゴ + URL
- X共有ボタン（Web Intents）+ OG画像（動的生成できればなお良い）
- 誤答3〜5個を縦に並べた縦長カードがXの feed で最も映える想定

## 6. 4モードの整理

| モード | 位置づけ |
|---|---|
| ① AI解読バトル | **フェイス**。ソロおもちゃ + マルチの核。リソースをここに注ぐ |
| ② プロンプト・テレポート | デモの引きとして温存（成果物チェーンの共有化は将来の拡張候補） |
| ③ スピード・スケッチ | 技術展示として温存（inpainting 合成のデモ） |
| ④ おじゃまバトル | 技術展示として温存（音声入力・演出のデモ） |

全部を均等に磨かない。①が刺さらば②〜④は「他にも作れる人」という証拠になる。

## 7. バズ設計の追加オプション

- **本日のお題**: 全員が同じお題でAIを騙す→AI騙し率を共有カードで比較（Wordle型の共有モーメント）。リピートと「みんなもやってる感」を作る最強の増幅器。要アカウント不要の軽量集計
- **お題の設計**: 具体的名詞はGeminiに即答される。騙せるのは文脈語（ミーム、内輪用語、抽象概念）。「騙しやすいお題」を意識して選ぶ/生成する
- **多言語**: 世界でバズらせるなら英語対応は実質必須。Gemini側はそのまま動くので、UIとお題リストの i18n + 共有カードの2言語化が主作業

## 8. ポートフォリオとしての必須要件

- 常時起動の本番URL（Render設定済み）+ 初回描画3秒以内
- README 先頭に15秒GIF（AIが誤答していく様 = 自動的にゲームの広告になる）
- 「1人でも完結する」デモ動画（採用者は仲間を集められない）
- 技術ストーリーの文書化: サーバー権威設計、Web Audio完全合成、Geminiコスト最適化（既存の強みで、これはコードとREADMEで伝わる形にする）

## 9. ロードマップ案

1. ** wedge（急ぎ）**: トップ=即描きおもちゃ化 / AIキャラ化（独り言表示）/ 共有カード生成 + X共有
2. **仕上げ**: OG画像、騙しやすいお題リスト再設計、英語お題 + UI i18n
3. **余力**: 本日のお題（Wordle型）、テレポートチェーンの共有カード化、モバイル描画UXの仕上げ
