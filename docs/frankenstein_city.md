# フランケンシティ（仮題）— CityGML混合都市の GeoGuessr × 大喜利 設計案

> 元アイデア: 「CityGMLで実際にその場所に行けるんだけど、2つの地域がミックスしていて、どこでしょう」
> 上位コンセプトは docs/asymmetry_lab.md（人間×AI 非対称研究所）の「常設展示」ポジション。

## 1. 一言コンセプト

**国土交通省 Project PLATEAU の3D都市データで、2つの地域を混ぜた「実在しない街」を作り、ブラウザで歩き回って「これはどこ？」を当てるゲーム。** 当てるのは人間の頭とAIの頭が競争し、違和感の言語化は大喜利で票を競う。

## 2. なぜ面白いのか: この素材の非対称構造

| | 人間 | AI (Gemini Vision) |
|---|---|---|
| 学習分布 | 実世界を身体で歩いている | **実写写真で学習**。CityGMLの無機質レンダリングは分布の外 |
| 認識の拠り所 | 交差点の形・地形・坂・街区の配置という**身体記憶**（「この角、通ったことある」） | 看板・人・車・店という**テクスチャ情報**に依存 |
| CityGML上での結果 | 素材が素朴でも「あれ、ここ渋谷では?」と当てられる | 幻覚が出る。「ハチ公像が見えます」→ **データには犬はいない** |
| 弱点 | 初見の街は全く分からない | 画像スタイルの変化に脆い。自信満々に間違える |

→ AIの幻覚を**人間が実況でツッコむ**構造が自然に生まれる。「幻覚見抜き」実験の地理版であり、素材が風化しない（実写でなく3D都市で学習したモデルが出てこない限り）。

## 3. モード設計

### モードA: どこでしょう（GeoGuessr本体）
1. 混合街の任意の場所に立つ（自由移動）
2. 全員が2本のピンを地図に刺す: ①ベースの街 ②混入している街
3. GeoGuessr式の距離減点（近いほど高得点）。2本合計で競う

### モードB: 違和感探し（1個混入）
- 1つの街区に、別の街の建物が1棟だけ混入している。それを探してクリック
- 人間は「縮尺が変」「向きが 北向きじゃない」で見つける。**AIにも同じスクショを見せて同時に当てさせ、外れたら画面に堂々と表示**（採点者ではなく敗者としてのAI）

### モードC: AI案内人（幻覚を探せ）
- AIが「この街の案内人」として行き先をナビする（スクショ→説明→次の方向）
- AIは実在しないランドマーク・店・乗り物を幻覚しながら歩く
- プレイヤーは「今の説明、幻覚だろ」を当て続ける。AIのナビがどこで破綻するかを観察するショー
- 実装: スクショ→Gemini Vision→ナビテキストのループ。既存のAI推測ループ（geminiAI.ts）と同じ構造

### モードD: 住民大喜利（私的文脈の砦）
- この実在しない街について「この市の標語を書け」「住民の一日を説明しろ」「市のうわさをでっち上げろ」
- 投票で一番面白い Answer が勝つ。**混合街という架空の文脈**が、大喜利の引き出しをその場で作る

### モードE: 旗取りレース（マルチ対戦）
- 「混入建物を見つけた人が旗を立てる」早抜け競争。見つけたら旗が立ち、他プレイヤーは旗の近くだけを探索する追いかけ構造

## 4. データと実装パス

**データソース**: Project PLATEAU（CityGML / 3D Tiles、CC-BY 4.0、出典表記「国土交通省 Project PLATEAU」）。対象都市はデータの揃っている主要都市から選定。1ステージ=小さな街区単位で帯域を抑える。

**混合の作り方（オフラインパイプライン、scripts/の延長）**:
1. 地域Aの地形+道路をベースに
2. 地域Bの建物群を抽出→位置・向きを変えて移植
3. 結合したタイルセットを書き出し（ビルド時処理。ランタイムは合成済みを配信）

**段階的実装**:
| 段階 | 形態 | 理由 |
|---|---|---|
| v0 | **事前レンダリングした視点画像12枚**で遊ぶ画像版GeoGuessr | three.jsなしで成立。混合街のゲーム性を最速で検証 |
| v1 | three.js + 3D Tiles（3DTilesRendererJS）で**一人称歩行**、マルチ同期 | PLATEAUは3D Tilesを公式配布。Socket同期は既存基盤 |
| v2 | モードC/EのAIナビ・旗取り、モバイル操作最適化 | |

**AI連携**: canvas スクショ → Gemini Vision 1呼び出し。マイクロトランザクションで済むサイズ。

## 5. 世界観での位置づけ

研究所メタファーでの「常設展示」。実験カード型の軽いゲーム群（ドを歌え、幾何採点官、適当を読める）が「受付」で、ここが「来たからにはこれを遊べ」という目玉。PLATEAU×AI×大喜利は技術的にも話題的にもポートフォリオの記憶点になる。

## 6. リスク

| リスク | 緩和 |
|---|---|
| 3D表示のモバイル性能 | v0（画像版）を先に作り、性能はv1で段階検証。低解度タイル+移動制限 |
| PLATEAUの都市カバレッジの偏り | 揃っている都市をベースに選定。ステージ化して増やす |
| AIの地理推定が想定より強い/弱い | どちらに転んでも実験として成立（強すぎたら混合の複雑さを上げる）。ステージごとにチューニング |
| 混合の品質（ただのガチャガチャにならない） | 「地形はA、建物はB」「道路幅だけB」など混合パターンを設計して違和感に序列を作る |
