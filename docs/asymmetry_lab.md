# 人間×AI 非対称研究所（仮題）— 「能力の差」を遊び材にする設計案

> 元アイデア: 「AIの限界と人間の限界を使った遊びにしたい。人の音楽の再現能力のなさで遊ぶ、特殊なコンテクストを入れたAIは特殊な挙動をする、で遊ぶ」
> このドキュメントがプロジェクト全体の上位コンセプト。ワリオ構造（docs/ai_rush.md）と対戦ルール（docs/rule_breaker.md）はこの上に載せる"パッケージング"の選択肢になる。

## 1. デザイン原則

**ゲームの素材は「人間とAIの、測定可能な能力の非対称」に限る。**
「AIにしかできないこと」は演示になるだけで遊びにならない。「人間にしかできないこと」も同様。
遊びになるのは次の2類型:

- **両方できるが精度が違う**: 人間はドを歌えるが当てられない。AIは正確に測れるが歌えない
- **どちらかに原理的に不可能なこと**: AIはあなたの内輪ネタを永遠に知らない。人間は1秒に7個しか覚えられない

### 非対称の耐久性分類（素材選定の最重要軸）

| 種類 | 例 | 耐久性 |
|---|---|---|
| **生物学的限界** | 絶対音感の欠如、体内時計の誤差、ワーキングメモリ7個、記憶描画の崩壊（自転車問題）、色の記憶 | ★ 永遠に埋まらない |
| **私的文脈** | 内輪ネタ、個人の経験、その場の空気 | ★ 永遠に埋まらない |
| **現在のモデルの弱さ** | 文字描画、物体の数え、長会話の自己矛盾、幻覚 | △ モデル更新で消える。素材としては補助に留める |

→ ポートフォリオを★だけで組めば**一年後に古くなることはない**。△は「AIも進化している」という文脈演出・ドッキリ材料に回す。

## 2. ゲームカタログ

各ゲーム = 仮説（ひょっとして実験） → プレイ → 測定 → **測定結果がそのままシェアカード**。
[耐久]印: ★=生物/私的、△=モデル依存。

### 人間の限界シリーズ

**ドを歌え（絶対音感バトル）** ★
- 仮説: 人間は音程を再現できない。AIは完璧に測れるが音を出せない
- 遊び方: マイクで「ド」を2秒歌う。Web Audio（自己相関によるピッチ検出）でセント誤差を測定。全員の中で最も近い者が勝ち。逆モード: AIが基準音を止めてもらい、全員が今度は記憶だけで歌う（成功率がさらに落ちる）
- 判定: 周波数測定。決定論的。AIは「完璧な採点者」として登場（AIに歌は歌えない＝最初の非対称がルールに内蔵される）
- シェアカード: 「あなたのドは **+87¢** ズレていました（人間平均 +42¢）」

**10秒を数えろ（体内時計バトル）** ★
- 仮説: 人間の体内時計は環境次第で±20%ずれる。AIの時計はずれない
- 遊び方: スタートを押してから「10秒」と感じた所でストップ。誤差で競う。演出: AIが妨害する（「まだ12秒ですよ」と嘘をつく。人間は誘導に乗るか?）
- 実装: ほぼゼロコスト。嘘つき演出は純粋なLLMテキスト1回

**あなたの適当を読める（ランダム性バトル）** ★
- 仮説: 人間は「ランダム」を生成できない（繰り返しを避けたがる）。AIは人間の"適当"の癖を知っている
- 遊び方（双方向）: ①人間が1〜9を10個入力→AIが次の数字を予測、的中率で競う ②AIが1〜10を選ぶ→人間が読む。「AIが選ぶ数字は7に偏る」ことが体感できる
- 実装: Gemini 1トークン呼び出し、またはサーバー側の統計。ほぼゼロコスト
- シェア: 「あなたの適当、AIに68%読まれています」

**自転車を描け（記憶描画バトル）** ★
- 仮説: 人間は毎日見る自転車すら記憶から正確に描けない（フレーム構造が壊れる）
- 遊び方: 記憶だけで自転車を30秒で描く。AI Visionが構造異常（ペダルが浮いている等）を検出して採点、または他プレイヤーが「走れそうな自転車」投票
- 実装: 既存のDrawingCanvasとモード①の推測基盤をそのまま転用

**ロゴの色を当てろ（記憶色バトル）** ★
- 仮説: 人間は有名ブランドの色すら記憶できない。AIはhex値を知っている
- 遊び方: カラーピッカーで「コカ・コーラの赤」を選ぶ。ΔE（色距離）で採点。AIは永遠に満点（データは知っているが、画面の色はモニタ次第という人間側の最後の砦も面白い）
- 実装: ピッカー+距離計算のみ。超軽量

**一瞬記憶（0.5秒メモリバトル）** ★
- 仮説: 人間のワーキングメモリは一瞬の映像を保持できない
- 遊び方: 0.5秒だけ見せた絵を描き写す。AI Visionが類似度採点。要素数を増やすと人間の崩壊が加速する（7個の法則の体感）

### AIの限界シリーズ

**特殊コンテキスト推理（何を言われている?）** ★＋△
- 仮説: AIは特殊な文脈を与えると特殊な挙動をする。ならば挙動から文脈が逆算できる
- 遊び方: AIに秘密の指示が与えられている（「あなたは嘘しか言えない」「あなたは眠い」）。返答を見て、全員で「何を言われているか」を推理。フリーテキスト回答なら**大喜利になる**（面白い推測が投票で勝つ）
- 実装: テキスト生成のみ。ルールブレイカー（docs/rule_breaker.md）の正統な一般化＝この研究所のマルチプレイヤー看板ゲーム
- ここだけ「私的文脈＝人間の守備範囲」と「モデルの挙動」が交差する接点で、テーマの中心

**幻覚見抜き（実在する?）** △
- 仮説: AIは存在しないことを自信満々に言う。人間は疑える
- 遊び方: AIが生成した生物・歴史事実・地名のうち、実在するのはどれか。人間 vs AI の判別合戦（AIにも同じ問題を出し、幻覚を暴く）
- 注意: モデル更新で幻覚が減る=題材が風化する。v1では演出扱い

**あなたの自転車をAIに描かせろ（私的文脈バトル）** ★
- 仮説: AIは自転車を描けるが、"あなたの自転車"は描けない
- 遊び方: 自分の自転車を言葉で説明→AIが描く→本人が満足したら人間の勝ち。満足度投票。完璧で無味乾燥な自転車が「自分の」として受け入れられない体験そのものがゲーム
- テーマ的意味: 「私的文脈は人間の最後の砦」という耐久★素材の実演

**ハミングで曲当て（再現の悪魔）** ★＋△（実験的）
- 仮説: 人間のハミングは音痴だが、AIはそれでも曲を認識できる。人間には人間のハミングが分からない
- 遊び方: 有名曲をハミング→AIは当てる（検索エンジン級の精度）、他のプレイヤーは当てられない。あなたの音痴が問題になるのは人間相手の時だけ
- 実装: Geminiの音声入力にinline音声で投げる。精度が不確定なので実験枠

### 追加シリーズ（第二弾）

**幾何採点官（真円を描け/直線を引け/正三角形を描け）** ★
- 仮説: 人間の運動器はフリーハンドで真円を描けない。機械測定は永遠に正確
- 遊び方: タッチ/マウスで真円を描く→楕円フィッティングで歪み率%を採点（中心ズレ・半径分散）。連続で直線・正三角形へ。AIは「採点官」として完璧に登場
- 実装: 楕円フィッティングのみ。マイク許可すら不要で全実験中最軽量。スマホのタッチでも成立
- シェア: 「あなたの円の歪み率 **12.3%**（人間平均 8.9%）」

**帰り道再現（経路記憶バトル）** ★
- 仮説: 人間は10秒見た経路ですら再現できない
- 遊び方: 地図上の経路を10秒見る→記憶だけで描き直す→軌道類似度で採点。AIは完璧に記憶するが「道に迷う体験」はできない

**ポーカーフェイス（感情偽装バトル）** ★
- 仮説: 人間は感情を偽装できる。AIの感情推定は皮肉・私的文脈に弱く、嘘を見破れない
- 遊び方: 「本当は嬉しいが怒りを演じろ」→テキストで描写→AIが感情を推定。真の感情を保持したまま偽装を通せば人間の勝ち
- 大喜利性: 演技の文章そのものが面白くなる

**チューリング大喜利** ★
- 仮説: 人間は人間をAIだと思い込み、AIを人間だと思う。その勘違い自体が娯楽になる
- 遊び方: 1vs AI のフリーチャットを見て全員でどちらがAIか投票。加えて「AIっぽく振る舞う人間」枠も出走させ、混乱を極大化する。投票後の解説が大喜利
- 実装: チャット+投票のみ。実証済みのバズジャンル

**ぴったり50文字（トークンの壁）** △
- 仮説: LLMは文字数を数えられない（トークン≠文字）
- 遊び方: AIに「ちょうど50文字の文章」を書かせ、実文字数を当てる/人間が審査員。「AIの50文字は68文字だった」は今しか見られない光景。モデル更新で消えるので演出枠

## 3. 集合データという武器（この構想だけの成長エンジン）

各ゲームは測定値を生む。**全プレイヤーの測定値を蓄積すると、それ自体がシェア可能なコンテンツになる**:

- 「全人類の平均: あなたの『ド』は+42¢ズレる」「人間の10秒は平均11.3秒」「AIが言う1〜10の 分布、7が31%」
- 統計が溜まるほどカードが説得力を持ち、「実験」 framingが本物になる
- ポートフォリオの語り: 「遊べる実験装置を作り、訪問者ごとにデータが溜まる」 — 採用者が遊んだ瞬間にデータベースに一行加わる設計
- v1はローカル集計+簡易サーバー集計（単一ルーム基盤の延長）で十分

## 5. v1 選定（基準: 実装コスト×面白さ×耐久★×シェア可否）

0. **幾何採点官** — 全実験中最軽量（楕円フィッティングのみ・マイク不要）。まずこれで「実験カード→遊ぶ→結果カード」のUIフレームとデータ集計を作る
1. **ドを歌え** — Web Audioピッチ検出のみ。生物限界の王道。AI=完璧採点者の非対称が美しい。マイク許可が唯一の摩擦
2. **あなたの適当を読める** — 実装最小・概念が一番刺さる・コストほぼゼロ。デモの冒頭に最適
3. **特殊コンテキスト推理** — 大喜利×マルチ×既存資産の総決算。マルチの看板

＋ロビー/トップは「実験カード」形式（仮説1枚→遊ぶ→結果カード）に統一し、サイト全体の世界観を研究所にする。
