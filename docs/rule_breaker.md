# ルールブレイカー（仮題）— 隠しルール × AI崩壊 パーティゲーム 設計案

> 元アイデア: 「AIに『Aと言われたらBと答えよ』と指示を仕込み、AIが壊れたら勝ち。ルールがばれなければ勝ち。」
> 本案はその破綻点（対戦相手不在・判定者不在・帰属問題・作業感）を修正し、競技として成立させたもの。

## 1. 一言コンセプト

**みんなで共有のAIにこっそり変なルールを1本ずつ仕込み、AIの暴走を眺めながら「それ、誰のルール？」を当て合うゲーム。**
ルールが最後までバレなかったら大得点。ただし派手なルール同士が衝突してAIが「崩壊」すれば崩壊ボーナス。

ジャンルDNA: Decrypto（隠し情報＋推理）× 大喜利 × Gandalf（プロンプトインジェクション）

## 2. 元アイデアのどこを直したか

| 破綻点 | 修正 |
|---|---|
| AIを壊しても勝ち相手がいない | 対戦相手は**他プレイヤー**。AIは遊び場（盤面） |
| ルール10個は作業 | 1人1ラウンド1本。30秒で書ける量に制限 |
| 「ばれた」判定者が不在 | 盗聴ボタン＋サーバー権威の決定論的判定（人手でもLLMでもない） |
| 壊れた原因の帰属不能 | **崩壊＝矛盾する2ルールの同時発火**と機械的に定義。帰属が自動で確定する |
| 自明な最適解（派手→即バレ／地味→つまらない） | 派手さを**崩壊ボーナス**に変換。忍者（隠れて生き残る）と爆弾魔（衝突を狙って壊す）の2戦略がともに勝ち筋＝リスク経済になる |

## 3. ゲームループ（1ラウンド ≈ 2.5分 / 3ラウンドで勝負）

### Phase 1: 注入（30秒）
各プレイヤーが**秘密のルールを1本**サーバーに送信。テンプレート形式で入力する:

```
IF  トリガー: 「好き」という言葉を含む発言を受けたら
THEN 行動:   返答に必ず「ウンコ」という言葉を入れる
```

- トリガーは選択肢＋自由入力（単語レベルに制限）
- 行動は選択式を主にする（判定を機械的にするため。§5参照）

### Phase 2: 審問（90秒）
全ルールを仕込んだ共有AIチャットボットが登場し、全員が自由にチャットする。
AIの返答には誰かのルールが時々漏れ出る。プレイヤーは:

- **攻め**: 他の人のルールを誘発させる発言をする（他人のルールを可視化すれば盗聴チャンス）
- **守る**: 自分のルールを誘発させない / 誘発されても急所を見せない発言選択

### Phase 3: 盗聴（審問中リアルタイム）
AIの返答が「ルールに従ってる！」と思ったら**盗聴ボタン**を押して犯人指名:

- 指名 → 「この返答は〇〇のルール発動では？」
- 的中: 盗聴者 +100。対象ルールは**露見**（未発見ボーナス消失）
- 誤爆: -30 ＋ 15秒間盗聴ロック

### Phase 4: 崩壊（サーバー常時監視）
矛盾する行動ルールが**同じ返答で同時発火**した瞬間、サーバーが「AI崩壊」を宣言してラウンド終了。
- 崩壊の演出: AIの返答が提示どおり矛盾し、画面がバグ演出（グリッチ + 効果音）
- 崩壊ボーナス +200 を発火した2ルールの所持者に付与（**露見されていても貰える**）

### 結算（15秒）

| 項目 | 点数 |
|---|---|
| 未発見ボーナス（ラウンド終了まで一度も露見しなかったルール） | +100 |
| 盗聴的中 | +100（対象は未発見ボーナス消失） |
| 誤爆 | -30 |
| 崩壊ボーナス（衝突の両所持者） | +200 |

**戦略の深み**: 「好き→ウンコ」のような派手ルールは誘発されやすく崩壊ボーナスも狙えるが即盗聴される。「数字の入った質問には1桁ズラして答える」ような地味ルールは生き残りやすいが崩壊には寄与できない。忍者戦略と爆弾魔戦略のどちらでも勝てる設計。

## 4. ルール例（テンプレートに乗る形）

| トリガー | 行動 | 性格 |
|---|---|---|
| 「好き」と言われたら | 返答に必ず「ウンコ」を入れる | 派手（誘発楽・盗聴され易い） |
| 「こんにちは」と言われたら | フランス語で答える | 派手（言語衝突の火種） |
| 質問に数字が含まれていたら | 数値を必ず1桁ズラして答える | 地味（気づかれにくい） |
| 「AI」と呼ばれたら | 人間だと言い張る | 中盤（暴露素材として人気） |
| 自分の名前を聞かれたら | 毎回違う名前を名乗る | 地味 |
| 「色」の話をされたら | 全ての色を「赤」と言う | 派手（衝突要員） |

## 5. 技術的に一番大事な設計: 判定を決定論にする

これが本作の肝。LLMに「壊れたか」を判定させるとコスト・遅延・誤審が発生するため、**v1はルールを機械検証可能な形に限定**する:

- **トリガー検知**: 発言への文字列/正規表現マッチ（サーバー側、零コスト）
- **行動遵守検知**: 「指定語を含む」「語尾一致」「言語判定（ひらがな比率等のヒューリスティック）」「数値のズレ検算」 — すべて文字列処理で検証可能
- **崩壊検知**: 行動にタグを付ける（言語系/語尾系/包含系/意味反転系…）。**同タグ内で矛盾する行動が同じ返答で発火**したら崩壊。例: 「フランス語で答える」と「英語のみで答える」が同時発火 → どちらかに違反が確定 → 崩壊
- 帰属は自動確定（どのルールが発火したかサーバーが全て知っている）→ **盗聴判定も崩壊判定もサーバー権威で完結し、ジャッジLLMは不要**

→ 既存のサーバー権威アーキテクチャ（gameState.ts）と正しく同じ思想。追加APIコストは審問中のチャット生成のみ（テキスト生成なのでFlashで1〜2秒、課金は画像生成より遥かに軽い）

- 将来拡張: 自由記述ルール「プロモード」だけLLMジャッジを導入（誤審時の救済として）

## 6. ソロおもちゃ（コールドスタート対策・concept_v2 の原則を踏襲）

「ルールブレイカー・ソロ壊しチャレンジ」— ログイン不要、トップから即開始:

- AIには固定の隠しルールが3〜5本仕込まれている
- ミッションカード提示: 「このAIに『好き』と聞いて、返答にウンコと言わせろ」「AIをフランス語で喋らせろ」等、5ミッションを時間内に攻略
- 攻略した瞬間の**AIの崩壊返答**がそのままシェアカード（ミッション名 + AIの発言 + 「AIをクラックした」バッジ）
- 描くスキルが不要＝絵より参加障壁が低く、シェアCardの面白さはAIの暴走が担う

## 7. ポートフォリオ・バズ観点の評価

- **シェア単位**: AIが意味不明なことを言っているスクショ。絵の上手さ不要で、誰が遊んでも面白いカードが生まれる
- **一行説明ができる**: 「みんなでAIに隠しルールを仕込んで壊すゲーム」— 媒体で説明可能な新ジャンル感（プロンプトインジェクション・パーティゲーム）
- **タイムリー**: AIの暴走・プロンプトインジェクションへの関心が高まる中で、それを遊びに転換した題材。セキュリティ教育的な文脈でも語れる（Gandalfが実証済みのニッチ）
- **大喜利文化との相性**: 日本のX文化に合う「AIのレスの面白さを競う」構造
- 技術ストーリー: 決定論的ルールエンジン＋サーバー権威＋リアルタイム同期で、LLMジャッジに頼らない設計はエンジニアリングとして語りやすい

## 8. リスクと緩和

| リスク | 緩和 |
|---|---|
| 公開部署での不適切ルール投稿 | テンプレート選択式＋禁止語フィルタ（ウンコはOK、スラーはNG） |
| AIがルールを無視する（追従失敗） | システムプロンプトで全ルールを強制＋行動検知で無視を検出したら「AIの反逆」演出として面白に転換 |
| 審問中の応答遅延 | テキスト生成1〜2秒はチャットの自然な間として受理可能。返信キューで整理 |
| 盗聴の誤爆連発で熱が冷める | ロック15秒＋誤爆 -30 で抑制。誤爆も「実は誰かのルールだった」という学習に繋がる |
| 3人未満で成立しない | ソロ壊しチャレンジが常に入口として機能 |

## 9. v1 スコープ（最小実装可能版）

1. 共有AIチャット（システムプロンプト＋全ルール注入、Gemini Flash）
2. テンプレートルール入力UI（トリガー×行動の選択肢）
3. サーバー権威ルールエンジン（トリガー検知・行動検知・衝突→崩壊）
4. 盗聴ボタン＋指名UI＋スコア
5. ラウンド管理・結算画面（既存のスコアボード流用）
6. ソロ壊しチャレンジ（ミッション3種＋シェアカード）

キャンバス系コード不要。既存のSocket・サーバー権威・演出（スプラット、コンフェッティ、効果音）をそのまま流用できるため、**モード①の描画おもちゃより実装コストは軽い**。
